# 永定河数字博物馆

一条河与一座城的八百万年。纯静态网站：HTML + CSS + 原生 JavaScript，无框架、无构建、无依赖。

## 页面

| 文件 | 页面 |
| --- | --- |
| 首页.html | 首页：加载页、首屏、序厅、意义四卡、数据、六展厅、流域图、时间轴、馆藏精选 |
| 永定河志.html | 永定河志：源流、可交互流域图（卫星底图）、河流的意义、时间轴、水利、文化遗产、生态重生 |
| 历史.html | 永定河的历史：19 节点时间轴（6 个时期）、古今作用对比表、现代影响五个方面 |
| 数字展厅.html | 数字展厅总览：六厅索引、推荐展线、临展 |
| 序厅.html / 第一展厅.html … 尾厅.html | 六个展厅详情页 |
| 馆藏精粹.html | 馆藏精粹：18 帧影像与器物，7 类筛选，详情弹窗 |
| 参观指南.html | 参观指南：开放时间、门票、交通、路线、服务、须知、FAQ |
| 图片展示.html | 图片来源与许可 |

## 智能体

`智能体.js` 是一个纯前端问答智能体：内置 50 条永定河知识，按主题词与问句相似度检索作答；与永定河无关的问题一律回复固定话术。所有页面已在 `</body>` 前引入：

```html
<script src="智能体.js" defer></script>
```

## 部署

- 纯静态，直接把整个文件夹作为站点根目录即可；
- Cloudflare Pages：Framework 选 None，Build command 留空，Build output directory 填 `/`；
- 图片许可：CC BY / CC BY-SA / 公有领域，逐张登记在「图片展示.html」。
